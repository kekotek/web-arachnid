# Bruce y sus variantes

Todo el arte de control utiliza **pose A**, con ambos brazos rectos a **45° del torso vertical**. Cada variante reúne el PNG de arte conceptual, el SVG de escala y las imágenes sin rótulos para crear el modelo 3D.

Las longitudes originales se mantienen: altura total **180 cm**, brazo **32 + 26 + 18 = 76 cm** y pierna **46 + 41 + 8 = 95 cm**. Los anchos y profundidades siguen en las medidas maestras. Las cotas horizontales de brazos en pose A se derivan de esas longitudes; no son nuevas medidas del cuerpo.
