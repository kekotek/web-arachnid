# web-arachnid

## Idea del juego

Crear un juego en **Unreal Engine** con un estilo **2.5D**.

Las plataformas objetivo son **Nintendo Switch, PlayStation 5 y PC**.

Las ideas del juego se encuentran en [ideas.md](ideas.md).

Explora el arte conceptual en la [galería HTML](concept-art/index.html). La [guía del archivo](concept-art/README.md) explica la organización de las imágenes y las referencias de Bruce para Meshy.

Cada traje tiene una [lámina de escala y proporciones](concept-art/index.html#tema=trajes&buscar=medidas) con frente, ambos perfiles, espalda y las alturas objetivo del personaje de 1,80 m.

## Inspiraciones

- Hollow Knight
- Silksong
- Well Dweller

## Personaje principal

El personaje principal está inspirado en **Spider-Man**.
